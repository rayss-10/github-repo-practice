# JavaScript Basics – Quick Revision Repo 🚀

This repository contains a **single JavaScript file (`js_basics.js`)** that works as a **one-stop revision sheet** for JavaScript fundamentals.

It is designed so that you can:

* Open one file
* Scroll top to bottom
* Revise concepts **in order**, from basic to core JS

Perfect for **beginners**, **quick revision before exams/interviews**, or when you just want to refresh JS fundamentals.
